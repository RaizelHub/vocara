# VOCARA Brand Assets

Tagline: **Speak better. Interview smarter.**

## Master Artwork

- `vocara-symbol.svg`: primary coral symbol on transparent background.
- `vocara-symbol-light.svg`: one-color light symbol for dark/coral surfaces.
- `vocara-horizontal.svg`: horizontal symbol and dark wordmark.
- `vocara-horizontal-dark.svg`: horizontal symbol and light wordmark.
- `vocara-app-icon.svg`: full-bleed warm off-white app icon master.
- `vocara-adaptive-foreground.svg`: transparent Android adaptive foreground.
- `vocara-monochrome.svg`: Android themed icon master.
- `vocara-splash.svg`: transparent splash-screen symbol.
- `vocara-brand-board.svg`: editable presentation board.
- `vocara-brand-board.png`: 1920 x 1200 presentation export.

## Production Exports

- `../images/vocara-icon.png`: 1024 x 1024 opaque iOS and legacy icon.
- `../images/vocara-adaptive-foreground.png`: 1024 x 1024 transparent Android foreground.
- `../images/android-icon-monochrome.png`: 432 x 432 transparent themed icon.
- `../images/splash-icon.png`: 1024 x 1024 transparent splash image.
- `../images/favicon.png`: 256 x 256 opaque web icon.

## Color

- Vocara Coral: `#FF5A36`
- Coral Light: `#FF7555`
- Coral Highlight: `#FF8A70`
- Ink: `#151515`
- Warm White: `#F7F7F3`

Do not add a rounded-corner mask to `vocara-icon.png`; iOS and Android apply
their own platform masks. Keep adaptive and splash exports transparent.
